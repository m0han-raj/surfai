SurfAI

A personal AI assistant that lives in the Chrome Side Panel. Ask it anything, ask it about the page you are on, and when you want something done, it can act on that page for you.

This address is the backend API. The interface is a Chrome extension, so there is no web app to open here.

How it works

Most of what you say is answered in a single turn, like any assistant. Acting on a page is the exception, and it is the part built carefully: the page is reduced to a compact list of labelled controls rather than raw HTML, one step is planned at a time against a fresh snapshot, and a risk classifier written in plain Python decides what needs your confirmation.

That last part matters. Webpage text is attacker-controlled, so the model is never trusted to decide what is safe. Purchases, payments, deletions and account changes always stop and ask.

Install

  1. Clone the repository and run npm install && npm run build in extension/.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select extension/dist.
  4. Open Settings in the panel and point it at a backend.
You can run the backend yourself with docker compose up, which keeps page content on your own machine and needs no sign-in. This hosted instance requires a Google account.

API

GET  /health            service and database status
GET  /health/llm        model endpoint probe
POST /api/chat          send a message
POST /api/tasks         start a browsing task
     /api/favourites    saved pages and their intent

Everything except the health endpoints requires a bearer token. See the API reference.
